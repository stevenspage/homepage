========================================
GitHub Pages 快速设置指南
========================================

✅ 你必须完成以下设置才能访问网站！

📍 设置地址：
https://github.com/stevenspage/homepage/settings/pages

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 1：启用 GitHub Pages
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 访问上面的链接（或：仓库 → Settings → Pages）

2. 找到 "Build and deployment" 部分

3. 在 "Source" 下拉菜单中，选择：
   ✅ "GitHub Actions"
   ❌ 不要选择 "Deploy from a branch"

4. 保存设置（会自动保存）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 2：触发部署
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

方式 A：自动触发（推荐）
- 推送任何代码到 master 分支即可自动触发

方式 B：手动触发
1. 访问：https://github.com/stevenspage/homepage/actions
2. 点击左侧 "Deploy to GitHub Pages"
3. 点击 "Run workflow" 按钮
4. 选择 master 分支
5. 点击绿色 "Run workflow" 按钮

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
步骤 3：等待部署完成
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 访问 Actions 页面查看进度：
   https://github.com/stevenspage/homepage/actions

2. 等待所有步骤显示绿色 ✅（约 3-5 分钟）

3. 部署成功后，访问你的网站：
   🌐 https://stevenspage.github.io/homepage/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
⚠️ 重要提示
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- URL 末尾必须有 /homepage/ 路径
- 首次部署后可能需要等待 5-10 分钟才能访问
- 如果显示 404，确认：
  1. Settings → Pages 已选择 "GitHub Actions"
  2. Actions 中的部署工作流已成功完成
  3. 等待几分钟后重试

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔍 检查清单
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

□ Settings → Pages 中选择了 "GitHub Actions"
□ Actions 页面可以看到 "Deploy to GitHub Pages" 工作流
□ 工作流运行成功（绿色 ✅）
□ 可以访问 https://stevenspage.github.io/homepage/

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

如果遇到问题，查看详细文档：SETUP_GITHUB_PAGES.md
